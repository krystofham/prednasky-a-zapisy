| Typ útoku                                      | Popis                                                                                                                                     |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Phishing (Email Phishing)**                  | Podvodný e-mail obsahující odkaz nebo přílohu, která se tváří jako důvěryhodná a má přimět oběť zadat citlivé údaje nebo spustit malware. |
| **Spear Phishing**                             | Cílený phishing zaměřený na konkrétní osobu nebo organizaci. Útočník si předem zjistí informace o oběti, aby e-mail působil důvěryhodně.  |
| **Whaling**                                    | Speciální forma spear phishingu zaměřená na vedoucí pracovníky (CEO, CFO, manažery) nebo jiné vysoce postavené osoby.                     |
| **Vishing (Voice Phishing)**                   | Phishing prováděný po telefonu. Útočník se snaží přesvědčit oběť, aby sdělila citlivé informace.                                          |
| **SMS Phishing (Smishing)**                    | Phishing prostřednictvím SMS zpráv obsahujících škodlivé odkazy nebo výzvy k zadání údajů.                                                |
| **USB Drop Attack (USB Drop Key)**             | Útočník nechá na veřejném místě USB disk s malwarem a spoléhá na to, že jej někdo připojí k počítači.                                     |
| **Watering Hole Attack**                       | Útočník kompromituje webovou stránku, kterou cílová skupina pravidelně navštěvuje, aby návštěvníky přesměroval na škodlivý obsah.         |
| **Pivot Attack**                               | Přesměrování uživatele z kompromitovaného důvěryhodného webu na škodlivý web. V textu je uvedeno jako součást watering hole útoku.        |
| **Caller ID Spoofing**                         | Falšování telefonního čísla při vishingu, aby se útočník vydával za důvěryhodnou osobu nebo organizaci.                                   |
| **Impersonation (vydávání se za jinou osobu)** | V textu se objevuje například vydávání se za kolegu (Chris) nebo vedoucího pracovníka při spear phishingu či whalingu.                    |
## Physical
| Typ útoku            | Popis                                                                                                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Piggybacking**     | Neoprávněná osoba vstoupí do zabezpečeného prostoru společně s oprávněnou osobou **s jejím vědomím nebo souhlasem**.                                                                          |
| **Tailgating**       | Neoprávněná osoba následuje oprávněnou osobu do zabezpečeného prostoru **bez jejího vědomí nebo souhlasu**.                                                                                   |
| **Dumpster Diving**  | Prohledávání odpadků nebo recyklačních kontejnerů za účelem získání citlivých informací (dokumenty, pevné disky, média).                                                                      |
| **Shoulder Surfing** | Získávání citlivých údajů (hesla, PII, PINy apod.) pozorováním obrazovky nebo klávesnice oběti. Může být prováděno zblízka, na dálku (dalekohledem) nebo pomocí skrytých kamer.               |
| **Badge Cloning**    | Klonování přístupových karet nebo vytvoření falešného firemního průkazu za účelem získání neoprávněného vstupu do budovy. Útočník může využít technické prostředky nebo sociální inženýrství. |
