## Derivace součinu
$$(f(x) g(x))' = f(x)' g(x) + f(x) g(x)'$$
## Derivace podílu
$$\big(\frac{f(x)}{g(x)}\big)' = \frac{f(x)' g(x) + f(x) g(x)'}{(g(x))^2}$$
## Derivace složené funkce 
$$f(g(x)) = (f \circ g)(x) = f'(g(x)) \cdot g(x)'$$
## Derivace absolutní hodnoty 
$$sgn(x)$$
```python
if sgn > 1:

	x = 0

	x < 0
```
